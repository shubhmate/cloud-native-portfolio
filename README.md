# Static DevOps Portfolio Website

This is a portable, high-performance static portfolio website built with HTML5, Tailwind CSS, and Vanilla JavaScript.

## Features

- **Static Site**: No server-side languages, runs directly in the browser
- **Responsive Design**: Mobile-friendly dark theme
- **Interactive Elements**: Typewriter effect, particle animation, terminal simulator, flip cards
- **Contact Form**: Integrated with Formspree for easy contact handling
- **Resume Download**: Prominent download button for your resume

## Setup Instructions

1. **Replace Placeholders**:
   - Update all `your-github-handle`, `your-linkedin-profile`, etc. with your actual links
   - Replace `your.email@example.com` with your email
   - For the contact form, sign up at [Formspree](https://formspree.io) and replace `your-formspree-id` with your form ID

2. **Add Resume**:
   - Place your resume as `resume.pdf` in the same directory as `index.html`

3. **Hosting**:
   - Upload `index.html` and `resume.pdf` to any static hosting service (GitHub Pages, Netlify, Vercel, etc.)
   - No build process required!

## File Structure

```
/
├── index.html          # Main website file
└── resume.pdf          # Your resume (add this file)
```

## Customization

- **Styling**: All styles are inlined or via Tailwind CDN
- **Icons**: Uses Lucide icons via CDN
- **Fonts**: Inter and JetBrains Mono from Google Fonts
- **Colors**: Dark theme with blue accent colors

## Browser Support

Works in all modern browsers that support ES6+ JavaScript.
