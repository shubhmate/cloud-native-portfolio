How This Site is Built

This portfolio is itself a DevOps project — deployed via a fully automated CI/CD pipeline on AWS infrastructure provisioned with Terraform.

Git Push

Push to main branch triggers the pipeline

Test & Lint

GitHub Actions runs ESLint + TypeScript checks

Terraform Apply

Provisions S3 bucket & CloudFront distribution

S3 Sync

next build output synced to S3 bucket

CF Invalidation

CloudFront cache invalidated for instant updates

.github/workflows/deploy.yml 
name: Deploy Portfolio Website            
  on:
    push:
      branches: [main]

  jobs:
    deploy:
      runs-on: ubuntu-latest
      steps:
        - uses: actions/checkout@v4
        - uses: actions/setup-node@v4
          with: { node-version: '20' }
        - run: npm ci && npm run build
        - uses: aws-actions/configure-aws-credentials@v4
          with:
            aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
            aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
            aws-region: us-east-1
        - run: aws s3 sync out/ s3://${{ secrets.S3_BUCKET }} --delete
        - run: aws cloudfront create-invalidation \\
                --distribution-id ${{ secrets.CF_DIST_ID }} \\
                --paths "/*"
